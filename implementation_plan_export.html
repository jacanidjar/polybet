Implementation Plan - Polybet (Polymarket Clone)

Date: 2026-01-08

Goal: Develop a high-performance, decentralized prediction market platform ("Polybet") similar to Polymarket.

1. Executive Summary & Critical Notices

IMPORTANT: Authentication & Onboarding
We will implement Social Login (Google, Email) alongside standard Metamask connections using a provider like Web3Auth or Privy. This allows "Account Abstraction" - creating a wallet for the user automatically behind the scenes, fulfilling the "Login only, no documents" requirement.
NOTE: Regulatory Notice
While betting itself won't require KYC (interacting with the blockchain), purchasing crypto with Fiat (Cards/Bank) via On-Ramps usually does require KYC by the third-party provider. We will integrate the widget, but the KYC burden lies with the provider.
IMPORTANT: DevOps & Environments
We will strictly separate Test and Production.
  • Test Environment: Uses Polygon Amoy Testnet (Fake Money).
  • Production Environment: Uses Polygon Mainnet (Real USDC).

2. Technology Stack & Rationale

Component Technology Rationale
Frontend Next.js 14 (App Router) React-based, excellent SEO, server-side rendering.
Styling TailwindCSS + Shadcn/UI Premium/Modern look. Fast development.
Smart Contracts Solidity (Polygon) Low gas fees. Gnosis Conditional Tokens Standard.
Auth & Wallet Privy Hybrid Auth: Google/Email AND Metamask.
Backend API NestJS (Node.js) Scalable. Handles AI agents and order caching.
AI Agent LangChain + OpenAI Support Bot for user guidance.

3. System Architecture

The system utilizes a hybrid decentralized architecture:

[User] -> [Frontend (Next.js)] -> [Auth: Privy/Social]
                               |
                               +-> [Backend API (NestJS)] -> [AI Service]
                               |                          -> [Database]
                               |
                               +-> [Blockchain (Polygon)] -> [Smart Contracts]

4. Core Features Scope

A. Betting Mechanism ("The Polybet Standard")

  • Choose Market: User selects "Will X happen?".
  • Buy Shares: User buys "YES" or "NO". Price reflects probability (e.g., $0.60 = 60% chance).
  • Investment: App sends USDC -> Contract -> Returns Shares.
  • Profit:
    • Sell Early: Market moves in favor, sell for profit.
    • Hold to Maturity: If correct, redeem for $1.00.

B. AI Agent Integration

  • Role: Customer Support & Guide.
  • Capabilities: Explains markets, guides deposits, clarifies rules.

C. Payments

  • Crypto Deposit: Send USDC (Polygon) to wallet address.
  • Fiat On-Ramp: Integrated widget (Stripe/MoonPay) for Credit Card purchases.
